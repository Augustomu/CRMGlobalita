# D04 · Fase 2 existe dos veces

**Problema.** *Fase 2* es a la vez una `etapa` y una etiqueta del catálogo libre. Lo mismo pasa con *Recordatorio* y *Reagendar*, que huelen a estado. Dos representaciones de lo mismo divergen en un mes.

**Opciones.**
- **A. El estado manda.** La etiqueta se genera sola y no se puede sacar a mano.
- **B. Son cosas distintas** y hay que documentar qué significa cada una.

**Recomendación: A.** Con una excepción práctica: la etiqueta sigue existiendo para filtrar, pero es de solo lectura.
