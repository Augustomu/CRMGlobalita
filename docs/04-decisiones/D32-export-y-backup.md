# D32 · Export y backup

**Problema.** La especificación no menciona backup ni export en ninguna parte, con 27.000 perfiles y un historial de envíos que es la base de toda la analítica.

**Resuelto.** Export completo (CSV/JSON) y backup diario automático entran en la **etapa 1**, no al final. Detalle en [[backups]]. Es lo que evita repetir la pérdida de datos de septiembre de 2026.
