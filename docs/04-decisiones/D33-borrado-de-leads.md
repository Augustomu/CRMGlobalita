# D33 · Borrado de leads

**Problema.** No hay borrado en ninguna pantalla, ni papelera, ni una salida real para *No target* (que hoy es solo una etiqueta). Con el reciclado cada 150 días, la base solo crece.

**Recomendación.** **Archivar, no borrar:** un `estado_cadencia = descartado` con motivo (no target, pidió no ser contactado, empresa equivocada). Sale de todas las listas y consultas por defecto, no se recicla nunca más, pero sigue en la base compartida para que ninguna otra cuenta lo vuelva a invitar. El borrado duro queda solo para pedidos explícitos de la persona.
