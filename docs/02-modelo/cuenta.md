# Cuenta de invitación

Perfil de LinkedIn desde el que se invita y se escribe. Se identifica por una abreviatura de 2–3 letras: AL, DL, FR, ED, AU, AMU.

| Campo | Notas |
|---|---|
| `abrev` | AL, DL, … |
| `nombre_perfil` | nombre real del perfil de LinkedIn |
| `estado_sesion` | activa / caída / sin_vincular |
| `cupo_diario` | default 40, editable por cuenta |
| `objetivo_semanal` | default 200 |
| `sesion_wa` | activa / caída — WhatsApp se vincula por QR, **aparte** de LinkedIn |

**Hay 10 slots fijos.** Los no vinculados se muestran como *libre 7*…*libre 10*.

Ver [[cupos-y-listas]] y [[sesiones-caidas]].
